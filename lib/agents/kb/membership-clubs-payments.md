# Membership clubs, gift cards & reloadable cards — checkout

Use when the customer asks to **pay**, **complete an order**, or **checkout** with a **מועדון**, **כרטיס נטען**, **גיפט קארד**, **שובר**, or named benefit program — not for generic "what payment methods exist?" (keep that answer **short**).

## Supported membership / benefit programs (current)

We work with these programs (website and/or branches — rep confirms the exact flow):

- דולצ'ה ויטה
- מפעל הפיס (מוצרי **השטיח האדום** בלבד — שובר אחד, לא בשילוב עם BUYME/חבר)
- מועדון שלך
- מועדון טוב
- מועדון כרטיס נטען **חבר** (Hever)
- לאומי בונוס
- גיפט קארד **BuyMe** (BUYME)
- iStudent
- מגה לאן
- אזרחים / עובדי צה"ל
- אינטל
- משרד הביטחון

Also accepted (see main Payments FAQ): אשראי, Apple Pay, Google Pay, bit (אתר בלבד), העברה בנקאית (סניפים).

## How to answer (customer-facing)

1. **Keep it short** — do **not** paste the full standard payment list **and** the full club list in one message.
2. If the customer names a program **on this list** — confirm we work with it and that **a service rep can help complete the order** with that card/benefit (same idea as קוד זיכוי — not always self-service in the payment screen).
3. If the program is **not** on the list — do **not** say "אין לי מידע"; offer to connect **נציג שירות** to verify.
4. **Complete order / להשלים הזמנה** with reloadable or club card → **service** (`human_service` after brief confirm), not a long FAQ dump.

## Combination rules (remind only when relevant)

- BUYME: multiple vouchers OK; **not** with חבר or פיס in same transaction.
- פיס: השטיח האדום only; one voucher; **not** with BUYME/חבר.
- חבר: one benefit; **not** with BUYME/פיס.
